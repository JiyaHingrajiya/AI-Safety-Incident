# AI-Saftey-Incident-Dashboard

## Overview
An interactive web-based dashboard designed to monitor, filter, and report AI safety incidents. This project aims to provide a user-friendly interface for tracking AI-related safety events, facilitating better understanding and management of AI systems.

## Features
Incident Listing: View a comprehensive list of AI safety incidents with details like title, severity, and date.
Filtering: Filter incidents based on severity levels (Low, Medium, High) for focused analysis.
Sorting: Sort incidents by date to view the most recent or oldest events.
Detailed View: Expand individual incidents to read full descriptions and understand the context.
Incident Reporting: Submit new AI safety incidents through an intuitive form interface.

## Tech Stack
Frontend: HTML, CSS, JavaScript
Build Tool: Vite
Styling: CSS,Tailwind

## Prerequisites
Node.js (v14 or higher)
npm or yarn

## Setup Instructions
### 1.Clone the repository:
git clone https://github.com/JiyaHingrajiya/AI-Safety-Incident.git
cd AI-Safety-Incident

### 2.Install dependencies:
npm install

### 3.Run the development server:
npm run dev

The application will run on http://localhost:3000.
